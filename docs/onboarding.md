# Onboarding

1. Get access to the repository and accept the invitation.
2. Clone it and configure your identity:

   ```bash
   git config user.name "Your Name"
   git config user.email "you@example.com"
   ```

3. Read `CONTRIBUTING.md` and `docs/branching-strategy.md`.
4. Pick an issue labelled `good first issue`, create a branch and open a pull request.
5. Ask for review in the pull request, not in private messages, so context stays visible.
